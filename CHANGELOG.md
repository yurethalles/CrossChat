# Changelog

## 1.0.0

- Initial CrossChat release.
- Added bidirectional `/s` chat between two Valheim servers.
- Added authenticated direct TCP transport without an external relay.
- Added source server and original character name display.
- Added Marketplace KG Chat integration and native chat fallback.
- Added configurable delayed delivery for solo testing.
- Added targeted suppression of the harmless internal Server Bot warning.
